What's new in Summer 2.6.0

- A fast, skippable first setup helps you choose the interface language, country-based starter bookmarks, and which app and widget suggestions appear before you type.
- New crash recovery restores sessions more safely, isolates failed tabs, and offers Safe Mode or alternate-browser recovery after repeated startup failures.
- A sandboxed built-in PDF viewer opens documents inside Summer. Website file drops and Video Player now support more local video formats and reviewable HTTP streams.
- Password autofill is available from the context menu, credit-card autofill is more reliable, and private-tab, drag-and-drop, RTL title-bar, and Android viewport issues are fixed.
- Widgets have clearer visuals and controls, with a browser-owned Focus timer, stronger AI setup guidance, repaired Now Playing video relay, and safer external Custom Action targets.
- Extension installs now show preparation progress, Summer App names are localized, search tab titles update immediately, and Captain Word suggestions use better popular-site titles and artwork.

What's new in Summer 2.2.0

- The new built-in Video Player supports local files, direct HTTPS streams, subtitles, playback controls, picture in picture, and searchable media catalogs.
- The new built-in Summer CLI provides real PowerShell, Command Prompt, WSL, Python, IPython, and Node.js sessions, with completion, history, and favorite commands.
- Find in page now lives in the browser chrome and remains reliable through tab switches, tab closes, and fullscreen transitions.
- Browser chrome can follow the current tab's favicon color. Fullscreen overlays, Google sign-in, MetaMask flows, and shutdown cleanup are more reliable.
- Update actions now show a clear waiting state and prevent duplicate requests.
- Summer now uses Electron 43.2.0 and normal Chromium GPU behavior for Windows Store packages while retaining GPU sandboxing.

מה חדש ב-Summer 2.2.0

- נגן הווידאו המובנה החדש תומך בקבצים מקומיים, בהזרמות HTTPS ישירות, בכתוביות, בבקרי הפעלה, בתמונה בתוך תמונה ובקטלוגי מדיה עם חיפוש.
- Summer CLI המובנה החדש מספק הפעלות אמיתיות של PowerShell, שורת הפקודה, WSL, Python, IPython ו-Node.js, עם השלמה, היסטוריה ופקודות מועדפות.
- החיפוש בדף משולב כעת בממשק הדפדפן ונשאר אמין בעת מעבר בין כרטיסיות, סגירת כרטיסיות ומעברים למסך מלא.
- ממשק הדפדפן יכול להתאים את צבעו לסמל האתר של הכרטיסייה הנוכחית. שכבות במסך מלא, הכניסה ל-Google, תהליכי MetaMask וניקוי בעת סגירה אמינים יותר.
- פעולות עדכון מציגות כעת מצב המתנה ברור ומונעות בקשות כפולות.
- Summer משתמש כעת ב-Electron 43.2.0 ובהתנהגות הגרפית הרגילה של Chromium בחבילות Windows Store, תוך שמירה על ארגז החול של המעבד הגרפי.

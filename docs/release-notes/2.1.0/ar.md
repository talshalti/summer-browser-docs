ما الجديد في Summer 2.1.0

- توسعت توافقية إضافات Chrome لتشمل منافذ runtime والإشارات المرجعية وعناصر التحكم في حذف بيانات التصفح والتخزين المُدار والمتزامن وتخزين الجلسة والتنقل على الويب وتصحيح الأخطاء والإشعارات واللوحات الجانبية وبرامج المستخدم النصية ودعمًا أقوى لـ Declarative Net Request.
- أصبحت مطابقة طلبات الإضافات ودورة حياتها أسرع وأكثر موثوقية وعزلًا.
- تتوفر واجهة Summer Browser الآن بلغات أكثر بكثير، مع ترجمة محسنة في الإعدادات ولوحات الإضافات.
- يقدم Captain Word كتالوجات مواقع محلية تتوافق بشكل أفضل مع لغتك.
- تتيح وسوم التنقل الآن اختيار مطابقة أي وسم أو جميع الوسوم.
- إذا تعذر الوصول إلى موقع ويب، يمكن لـ Summer اقتراح تطبيق Summer مثبت يعمل دون اتصال لذلك العنوان.
- أصبحت إشعارات المتصفح أكثر تكاملًا واتساقًا.
- أصبح اكتشاف المتصفح الافتراضي في Windows أكثر دقة.
- أصبح تشغيل الوسائط على YouTube والاقتراحات وإجراءات عناصر واجهة المستخدم أكثر موثوقية.

What's new in Summer 2.1.0

- Chrome extensions now have broader compatibility, including runtime ports, bookmarks, browsing-data controls, managed, sync, and session storage, web navigation, debugging, notifications, side panels, user scripts, and stronger Declarative Net Request support.
- Extension request matching and lifecycle handling are faster, more reliable, and more securely isolated.
- The Summer Browser interface is now available in many more languages, with improved localization across settings and extension panels.
- Captain Word provides localized website catalogs that better match your language.
- Navigation tags now let you choose Match any or Match all.
- If a website is unavailable, Summer can offer an installed offline Summer App for that address.
- Browser notifications now share a more consistent integrated experience.
- Windows default-browser status is more accurate.
- YouTube media playback, suggestions, and widget actions are more reliable.

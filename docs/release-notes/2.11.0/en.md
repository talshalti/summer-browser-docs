What's new in Summer 2.11.0

- Choose ChatGPT or Claude extensions in AI settings and open your preferred AI beside the current webpage.
- Ask from the address bar, reuse existing conversations, and preserve drafts while switching tabs.
- Improved extension side panels, resizing, navigation, and installation error reporting.
- Discover changes with the new What's New walkthrough, available again from Help and About.
- Reduced background work with idle-time file indexing and bounded search queues.
- Improved saved-password recovery, tab saving, and Microsoft Store update recovery.

Desktop AI now uses installed extensions instead of the former custom assistant and Mesh Ollama. Existing conversations, settings, and credentials are retained. Voice transcription remains available separately.

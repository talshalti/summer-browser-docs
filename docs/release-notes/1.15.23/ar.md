الجديد في Summer 1.15.23

- أصبحت جميع مقالات Summer Docs المضمّنة متاحة بالإنجليزية والعبرية والعربية، مع إبقاء الشيفرة وأسماء الملفات والمسارات ومعرّفات API محايدة لغويًا.
- تغطي اختبارات إمكانية الوصول لوحة المفاتيح والتركيز ومعالم الصفحة والإعلانات والتباين وتقليل الحركة وإعادة التدفق بعرض 320 بكسل والتكبير بنسبة 200% وتخطيطات اليسار إلى اليمين واليمين إلى اليسار.
- تغطي اختبارات الأمان والعمل دون اتصال جميع مسارات التوثيق وموارده المسجلة، وسياسة المحتوى الصارمة، وعزل الجسور، والنص غير الموثوق الخامل، والروابط الخارجية المسموح بها والمرفوضة، وإعادة التحميل الحقيقية دون شبكة.
- تتحقق اختبارات التوثيق من البيانات الوصفية والمصادر المرجعية والروابط الداخلية وربط ملاحظات الإصدارات والحالات المترجمة وجميع أمثلة الشيفرة المضمّنة.
- تتحقق مسارات اختبار الحزمة والترقية من بقاء Summer Docs مضمّنة وقابلة للعمل دون اتصال ومحددة الإصدار ومن دون صلاحيات خاصة داخل ملفات شخصية مؤقتة.

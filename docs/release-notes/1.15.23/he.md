מה חדש ב-Summer 1.15.23

- כל מאמרי Summer Docs המובנים זמינים כעת באנגלית, בעברית ובערבית, בעוד שקוד, שמות קבצים, נתיבים ומזהי API נשארים ניטרליים לשפה.
- בדיקות נגישות מכסות מקלדת ומיקוד, אזורי עמוד, הכרזות, ניגודיות, הפחתת תנועה, פריסה ברוחב 320 פיקסלים, זום של 200% ותצוגות משמאל לימין ומימין לשמאל.
- בדיקות אבטחה ועבודה ללא חיבור מכסות את כל נתיבי התיעוד והנכסים הרשומים, מדיניות תוכן מחמירה, בידוד מגשרים, טקסט לא מהימן שאינו מופעל, קישורים חיצוניים מאושרים וחסומים וטעינה מחדש ללא רשת.
- בדיקות התיעוד מאמתות מטא-נתונים, מקורות קנוניים, קישורים פנימיים, מיפוי גרסאות, מצבים מתורגמים וכל דוגמאות הקוד המובנות.
- מסלולי בדיקה לחבילה ולשדרוג מוודאים ש-Summer Docs נשאר מובנה, זמין ללא חיבור, מתויג בגרסה וללא הרשאות מיוחדות בפרופילים חד-פעמיים.

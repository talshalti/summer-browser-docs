What's new in Summer 2.3.0

- Merged updated browser suggestion controls, including on-request suggestion visibility and support for suggestion images and tags in built-in widgets.
- Added support for showing and controlling widget suggestion tags, with a new option to hide tags in the UI.
- Improved built-in browser widgets with updated icons, image thumbnails, and broader polish across suggestion rendering.
- Added and improved browser agent functionality with scalable tools, multi-tool planning, tab-scoped actions, granular approval controls, clearer success/error reporting, and better recovery paths.
- Added support for Gmail mailbox and draft actions through the browser agent experience.
- Fixed shutdown behavior when auxiliary windows are hidden, improving cleanup reliability.
- Added clearer handling for the Microsoft Store update path when updates are paused, including better monitoring behavior.
- Refined phone UI behavior and made additional suggestion-visibility refinements.

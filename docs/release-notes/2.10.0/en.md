What's new in Summer 2.10.0

- Improve Microsoft Store update checks, download resuming, and restart-and-install recovery.
- Make tab closing faster and defer background-page loading after crash recovery.
- Protect affected Windows builds from Chrome Web Store page crashes; install extensions through Extensions Manager instead. Improve Mesh recovery after a network renderer fails.
- Move bookmark aliases into Shortcuts while preserving saved entries.
- Preserve File Explorer indexing roots when expanding search scope, and group hidden and system items.
- Register Summer for supported local file types and add OpenAI transcription to navigator dictation.
- Add multiple news sources and finance items to the ticker, and restore Recipes section history navigation.
- Add an Experimental Features widget with optional browser CPU profiling and a read-only Airit publication browser.

New usage and AI-request collection remains inactive in this release, with no new mandatory agreement prompt.

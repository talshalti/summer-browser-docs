What's new in Summer 2.4.0

- Open multiple regular and private browser windows, each with its own tabs, overlays, notifications, downloads, and browser actions.
- Review files dropped into Summer before opening them. Supported text files can be edited offline in the new Text Workspace, while PDFs, images, audio, and video are routed to the appropriate viewer.
- Personalize new tabs with built-in or local wallpapers. Personal images remain inside the current browser profile.
- Import bookmarks and passwords through a safer guided flow with selection, progress, conflict handling, and clearer results.
- Meet Recipes, an offline-first cookbook with recipe capture, search, meal planning, grocery lists, timers, cooking guidance, and backup import and export.
- Find Apps and Widgets more easily in a reorganized store, and learn features through contextual tips and Discover Summer.
- On Windows, Summer can handle email links through saved Gmail or Outlook accounts, with an operating-system fallback.
- Enjoy faster tab switching, improved Alias editing, customizable bookmark suggestion titles, richer artwork, and fewer duplicate suggestions.
- Trigger saved Custom Actions from 31 browser events—including navigation, tabs, downloads, connectivity, schedules, and modified key combinations—or combine them into 17 meta-event patterns such as inactivity, frequency, sequences, duration, and rate changes. Actions can also be pinned as movable one-click widgets, with exact scoping and private-window protection.
- On desktop, Chrome extension compatibility is now a supported Summer feature, with Chrome Web Store installation, permission review, automatic signed updates, debugging tools, and tested support for popular extensions. Platform- and API-specific limits remain documented.
- Experimental Mesh now includes connected-peer visibility, direct chat, and opt-in authenticated HTTP and SSH access.

What's new in Summer 2.7.0

- Chrome extension compatibility and validation coverage is substantially broader, with upstream test paths for uBlock Origin Lite, Adblock Plus, Bitwarden, MetaMask, React DevTools, Dark Reader, Privacy Badger, Vimium, and Violentmonkey. Fixes cover DNR, scripting, context menus, permissions, navigation, and runtime lifecycles without claiming complete Chrome parity.
- Website permission states now align more closely with Chrome, including delegated iframe permissions, while extension installation and browser-owned permission flows remain explicit and reviewable.
- File Explorer search is faster, resumable, and configurable, with live index refresh, folder exclusions, safer file opening, and clearer progress and recovery controls.
- Experimental Mesh adds profile-scoped My Devices connections and connected-app access, with tighter identity, credential-storage, and lifecycle handling.
- Widgets gain concurrent Carver canvases, minimizable folders, media context actions, and improved Now Playing controls, with fixes for private-window isolation and webpage image dragging.
- First Setup is clearer and more customizable. The address field can calculate expressions, tabs gain improved mouse and zoom controls, and AI setup supports remote agents with stronger guidance.

What's new in Summer 2.7.1

- Notes is a new private, offline-first Summer App for portable Markdown documents stored as ordinary UTF-8 text files. It includes Write and Preview modes, external-file updates, conflict handling, and optional experimental Mesh sync.
- File Explorer search now keeps indexing work away from the browser's main thread, applies large batches of live changes incrementally, and keeps completed results available when coverage is temporarily incomplete. Search also gains clearer filters, context actions, and reveal behavior.
- Crash recovery restores only recently open live tabs and discards stale snapshots, avoiding the return of older closed tabs.
- Installed Summer Apps can now appear as `sap://` address-bar completions. My Devices has a clearer Settings experience, and Captainword adds localized, browser-owned commands with appropriate private-window restrictions and exit confirmation.

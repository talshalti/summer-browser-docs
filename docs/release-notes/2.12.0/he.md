מה חדש ב־Summer 2.12.0

- הכירו את Founder’s Pass במחשב וב־Android: תמיכה ב־Summer במינוי חודשי לבחירתכם, במחיר 9.99 דולר ארה״ב, הכולל 500 דקות תמלול ו־100 נקודות זכות לתרגום בכל חודש. מצטרפים מהמחשב; Android תומך בחשבונות עם מינוי פעיל.
- הכתיבו משורת הכתובת או משדות נתמכים בדפי אינטרנט, ובדקו את הטקסט לפני הכנסתו. במחשב זמין גם וידג׳ט התמלול.
- במחשב, תרגמו טקסט ודפי אינטרנט בענן בפעולה מפורשת, לצד התרגום הקיים במכשיר.
- שתפו את מכסת המינוי בין מכשירים מקושרים ב״המכשירים שלי״ במחשב וב־Android. לאחר הקישור, כל מכשיר יכול להשתמש במינוי גם כשהמכשיר המקורי אינו מחובר.
- גלו את מדריך ההיכרות החדש של Founder’s Pass במחשב ונהלו את החשבון דרך הגדרות ← מינויים.

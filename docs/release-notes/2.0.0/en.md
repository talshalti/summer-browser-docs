What's new in Summer 2.0.0

- The product is now consistently named Summer Browser in the app and Windows package.
- New opt-in profiles provide separate settings, tabs, bookmarks, cookies, extensions, Summer Apps, autofill data, and saved credentials. Profile launching and switching also handle slower Windows starts.
- Per-profile language preferences now appear in Appearance. Private on-device translation supports many languages, shows download and translation progress with an estimated time, and retains models.
- Captain Word now defaults to the Top 100 sites, follows language preferences, offers regional controls, improves artwork, filtering, and deduplication, and lets you hide unwanted domains. Settings can remove bookmarks, and Chrome/Safari import menus are easier to use.
- Mesh is now a permanent bundled Summer App, disabled by default. When enabled, it creates or restores local profile identities and addresses. Peer transport remains inactive.
- Summer Apps gain platform declarations, language access, asynchronous suggestion refresh, and bounded data, credential, and secure-randomness capabilities.
- A shared TypeScript browser core and Summer App SDK support desktop and developing mobile apps; mobile distribution is not included.
- Back and Forward state and Google sign-in compatibility are improved.
- Windows Store updates now download and verify first, then let you restart normally, keep every open tab and restart, or wait.

מה חדש ב-Summer 2.0.0

- שם המוצר הוא כעת Summer Browser באופן עקבי ביישום ובחבילת Windows.
- פרופילים חדשים לבחירה מפרידים הגדרות, כרטיסיות, סימניות, קובצי Cookie, הרחבות, יישומי Summer, מילוי אוטומטי ופרטי כניסה. הפעלה ומעבר בין פרופילים תומכים גם בהפעלה איטית יותר של Windows.
- העדפות שפה לכל פרופיל נמצאות כעת במראה. תרגום פרטי במכשיר תומך בשפות רבות, מציג התקדמות הורדה ותרגום עם הערכת זמן ושומר מודלים שהורדו.
- Captain Word משתמש כברירת מחדל ב-100 האתרים המובילים, פועל לפי העדפות השפה, מציע בקרות אזוריות ומשפר תמונות, סינון ומניעת כפילויות. ניתן להסתיר דומיינים, להסיר סימניות בהגדרות ולייבא מ-Chrome ומ-Safari ביתר קלות.
- Mesh הוא כעת יישום Summer מובנה וקבוע שמושבת כברירת מחדל. לאחר הפעלה הוא יוצר או משחזר זהויות וכתובות מקומיות לכל פרופיל. תעבורת עמיתים עדיין אינה פעילה.
- יישומי Summer מקבלים הצהרות פלטפורמה, גישה לשפות, רענון הצעות אסינכרוני ויכולות מוגבלות לנתונים, פרטי גישה ואקראיות מאובטחת.
- ליבת TypeScript ו-SDK משותפים תומכים כעת במחשב וביישומי המובייל שבפיתוח; הפצת מובייל אינה כלולה.
- מצב הקודם והבא ותאימות הכניסה ל-Google שופרו.
- עדכוני Windows Store מורדים ומאומתים תחילה, ואז ניתן להפעיל מחדש כרגיל, לשמור את כל הכרטיסיות ולהפעיל מחדש, או להמתין.

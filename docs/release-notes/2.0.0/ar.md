ما الجديد في Summer 2.0.0

- أصبح اسم المنتج Summer Browser بصورة موحدة في التطبيق وحزمة Windows.
- توفر ملفات التعريف الاختيارية الجديدة إعدادات وألسنة وإشارات مرجعية وملفات ارتباط وإضافات وتطبيقات Summer وبيانات ملء تلقائي واعتمادات منفصلة. ويدعم تشغيلها والتبديل بينها بدء Windows البطيء.
- توجد تفضيلات اللغة لكل ملف في إعدادات المظهر. تدعم الترجمة الخاصة على الجهاز لغات عديدة، وتعرض تقدم تنزيل النموذج والترجمة والوقت المقدر، وتحتفظ بالنماذج المنزلة.
- يستخدم Captain Word افتراضيًا أكثر 100 موقع شيوعًا، ويتبع تفضيلات اللغة، ويوفر ضوابط إقليمية ويحسن الصور والتصفية وإزالة التكرار. ويمكن إخفاء النطاقات وإزالة الإشارات المرجعية من الإعدادات والاستيراد من Chrome وSafari بسهولة أكبر.
- أصبح Mesh تطبيق Summer مدمجًا ودائمًا ومعطلًا افتراضيًا. عند تفعيله ينشئ أو يستعيد هويات وعناوين محلية لكل ملف تعريف. ولا يزال نقل الأقران غير نشط.
- تحصل تطبيقات Summer على تعريف المنصات والوصول إلى اللغات وتحديث الاقتراحات غير المتزامن وإمكانات محدودة للبيانات والاعتمادات والعشوائية الآمنة.
- تدعم نواة TypeScript وحزمة SDK مشتركتان سطح المكتب وتطبيقات الأجهزة المحمولة قيد التطوير؛ ولا يشمل الإصدار توزيعها.
- تحسنت حالة زري الرجوع والتقدم وتوافق تسجيل الدخول إلى Google.
- تُنزّل تحديثات Windows Store وتُتحقق أولًا، ثم تتيح إعادة التشغيل العادية، أو حفظ كل الألسنة وإعادة التشغيل، أو الانتظار.

What's new in Summer 2.5.0

- Use the opt-in AI Assistant Agent mode to find and operate Summer's bounded browser tools, with visible progress, cancellation, continuation checkpoints, and confirmation for sensitive actions.
- Run more Chrome extensions with broader Manifest V2 and V3 API support, safer user-script startup, signed updates, permission review, and installation recommendations from supported websites.
- Automate saved Custom Actions from browser events and advanced event patterns, or pin an action as a movable one-click widget. Private windows remain protected.
- Find widgets faster with catalog search, refreshed artwork, and a new live Internet connection widget with clear working, offline, and checking states.
- Experimental Mesh improves authenticated coordinator connections and peer lifecycle safeguards while keeping networking consent-gated.
- Navigate more reliably with Back and Forward mouse buttons while floating widgets are visible, including zoomed and cross-origin pages.
- Packaging now validates bundled Summer App runtimes more thoroughly before a release candidate can proceed.

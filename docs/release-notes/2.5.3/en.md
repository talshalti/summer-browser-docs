What's new in Summer 2.5.3

- Import bookmarks, saved passwords, autofill profiles, and Chrome extensions from supported browser profiles with reviewable selection, safer authorization and cancellation, and better recovery from interrupted imports.
- Use built-in Downloads, History, and Settings pages. Download controls now appear in a clear bubble above the bottom progress line, with completion notifications and a direct `summer://downloads/` link.
- Chrome extensions work more reliably in private sessions, action popups, context menus, signed profile imports, and cleanup after navigation or shutdown.
- Autofill is more dependable in HTTPS login frames and across languages, while native prompts remain attached to the correct browser window.
- File Explorer gains protected native indexing and faster search. Navigator autocomplete, suggestion controls, and built-in artwork are also improved.
- Microsoft Store updates now recover more safely from paused or stalled operations, preserve ready-to-install state across restarts, and expose clearer diagnostics.
- Android navigation, WebView startup, keyboard handling, tab history, and authenticated experimental Mesh connectivity are more resilient. Hebrew and Arabic layouts and floating-widget focus are also improved.

מה חדש ב-Summer 2.5.3

- ניתן לייבא סימניות, סיסמאות שמורות, פרופילי מילוי אוטומטי ותוספי Chrome מפרופילים נתמכים, עם בחירה הניתנת לבדיקה, הרשאות וביטול בטוחים יותר והתאוששות טובה יותר מייבוא שנקטע.
- נוספו דפים מובנים להורדות, להיסטוריה ולהגדרות. פקדי ההורדה מופיעים כעת בבועה ברורה מעל פס ההתקדמות התחתון, עם התראות סיום וקישור ישיר אל `summer://downloads/`.
- תוספי Chrome פועלים באופן אמין יותר בחלונות פרטיים, בחלונות פעולה, בתפריטי הקשר, בייבוא חתום מפרופיל ובניקוי לאחר ניווט או סגירה.
- המילוי האוטומטי אמין יותר במסגרות התחברות מאובטחות ובשפות שונות, ותיבות דו-שיח מקומיות נשארות משויכות לחלון הדפדפן הנכון.
- סייר הקבצים כולל כעת אינדוקס מקומי מוגן וחיפוש מהיר יותר. שופרו גם ההשלמה האוטומטית בניווט, בקרת ההצעות והגרפיקה המובנית.
- עדכוני Microsoft Store מתאוששים באופן בטוח יותר מפעולות מושהות או תקועות, שומרים את מצב ההתקנה המוכנה לאחר הפעלה מחדש ומציגים אבחון ברור יותר.
- הניווט, הפעלת WebView, הטיפול במקלדת, היסטוריית הלשוניות וחיבור Mesh הניסיוני והמאומת אמינים יותר ב-Android. שופרו גם פריסות עברית וערבית והמיקוד בווידג׳טים צפים.

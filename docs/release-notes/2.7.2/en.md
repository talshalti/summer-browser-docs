What's new in Summer 2.7.2

- Summer now captures privacy-filtered crash reports automatically and delivers them through a restart-safe background uploader, helping Hike Tech diagnose failures without collecting page content, browsing history, credentials, or raw memory dumps.
- Startup and extension failures are better contained so a delayed extension or child-process crash is less likely to take down the browser or interrupt recovery.
- Crash recovery, multi-window ownership, Keep tabs, profile handling, and Summer-owned navigation are more reliable across abrupt exits and restarts.
- File Explorer indexing, Mesh experiences, onboarding, and browser widgets received broad reliability and layout improvements, including smoother Media Player behavior and stronger narrow-window support.
- Add configurable keyboard shortcuts and address-bar named commands for tab, bookmark, widget, Summer App, and left/right panel management, with conditions, placement options, and validated JSON import/export. Existing bookmark Aliases remain available, and the same browser commands are available to Custom Actions.

What's new in Summer 2.3.1

- Added direct navigation for `summer://` and `sap://` addresses typed in the address bar.
- Restored address-bar navigation to local `file:///` URLs, including PDF files.
- Restored user-entered `javascript:` addresses for running code in the current page.
- Improved mouse, wheel, and zoomed-coordinate input for embedded and out-of-process pages.
- Made suggestion filtering smoother and more reliable, including large lists, match-all tags, and localized system tag categories.
- Improved current-tab contrast when websites use dark theme colors.
- Added resilient Widevine recovery when an installed component is too old or an update is interrupted.
- Improved Microsoft Store updates by ignoring unrelated queue entries and recovering downloads that become stalled.
- Refined native interface wording across supported languages and clarified that Chrome extension compatibility remains in Beta.

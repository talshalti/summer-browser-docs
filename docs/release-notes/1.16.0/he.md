מה חדש ב-Summer 1.16.0

- התמיכה הניסיונית בתוספי Chrome פועלת כעת עם יותר תוספים פופולריים, כולל תהליכי רקע, סקריפטים לתוכן, אחסון, תפריטי הקשר, התראות וכללים לבקשות רשת.
- אפשר להתקין חבילות תוספים חתומות או לטעון תוספים לא ארוזים באמצעות תמונות מצב לקריאה בלבד, עם אבחון תאימות ברור יותר ופרטי מניפסט מתורגמים.
- פעולות התוספים והחלונות הקופצים בסרגל הכלים אמינים יותר ונשארים מבודדים מתוכן האתרים.
- Summer Docs הורחב עם עזרה למשתמשים, מדריכים למפתחים, מידע על פרטיות, מדיניות מוצר והנחיות להגשת אפליקציות.
- תוקנה פתיחה מחדש של כרטיסיות באמצעות ניווט במקלדת ושופר סמל שיוך קובצי PDF ב-Windows.

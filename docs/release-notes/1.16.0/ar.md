الجديد في Summer 1.16.0

- أصبح دعم إضافات Chrome التجريبي يعمل مع مزيد من الإضافات الشائعة، بما في ذلك مهام الخلفية ونصوص المحتوى والتخزين وقوائم السياق والإشعارات وقواعد طلبات الشبكة.
- يمكن تثبيت حزم الإضافات الموقعة أو تحميل إضافات غير مضغوطة عبر لقطات للقراءة فقط، مع تشخيص أوضح للتوافق وتفاصيل بيان مترجمة.
- أصبحت إجراءات الإضافات والنوافذ المنبثقة في شريط الأدوات أكثر موثوقية وتظل معزولة عن محتوى المواقع.
- توسعت Summer Docs لتشمل مساعدة المستخدمين وأدلة المطورين ومعلومات الخصوصية وسياسات المنتج وإرشادات إرسال التطبيقات.
- تم إصلاح إعادة فتح علامات التبويب عبر التنقل بلوحة المفاتيح وتحسين أيقونة اقتران ملفات PDF في Windows.

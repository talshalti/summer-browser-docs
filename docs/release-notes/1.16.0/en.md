What’s new in Summer 1.16.0

- Chrome extension compatibility now works with more popular extensions, including background workers, content scripts, storage, context menus, notifications, and network-request rules.
- Install signed Chrome extension packages or load unpacked extensions through read-only snapshots, with clearer compatibility diagnostics and localized manifest details.
- Extension toolbar actions and popups are more reliable and remain isolated from website content.
- Summer Docs now includes expanded user help, developer guides, privacy information, product policies, and app-submission guidance.
- Fixed reopening tabs from keyboard navigation and improved the Windows PDF file-association icon.

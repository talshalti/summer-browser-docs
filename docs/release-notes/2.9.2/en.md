What's new in Summer 2.9.2

- Use a roomier, more consistent Settings layout. Identity & Security now fills the available height, while Link opens with My Devices and puts adding a device first.
- See the services offered by nearby Mesh peers so you can understand how each device can connect.
- Apply bookmark context-menu actions to every selected bookmark instead of changing only one.
- Recognize tabs more easily in the Performance memory map through their site icons.
- Install Panic Button only when you want it. The optional app unlocks its restore-point settings, toolbar control, custom actions, and named commands without appearing on fresh profiles by default.
